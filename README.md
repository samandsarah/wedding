# Sarah & Sam - Puerto Rico celebration

Static guest site for December 4-6, 2026 in Ocean Park, San Juan.

## Local preview

From this repository:

    python3 -m http.server 8000

Then open http://localhost:8000/.

## Deployment

The site is published from the `main` branch as the GitHub Pages project site:

https://samandsarah.github.io/wedding/

It is dependency-free HTML, CSS, and JavaScript. The design combines the
wayfinding structure of the Cambridge wedding microsite with Número Uno's
pink-and-emerald botanical wallpaper, beach-house iconography, and a secondary
coquí mark.
